# Agent

Agent orchestration and MCP tool implementation for SimuLab.

## Structure

- `runner.py` - Agent execution loop
- `models.py` - Agent model integrations
- `mcp/` - MCP tool definitions and handlers
- `tools/` - Individual tool implementations
- `evaluator.py` - Rollout evaluation logic
- `recorder.py` - Execution recording and replay
